# Espaço Edi

Site do Espaço Edi (Unhas e Depilação), em São Bernardo do Campo - SP.
Instagram: @edi.unha.e.depilacao

HTML, CSS e JS puro, sem framework nem back-end.

## Arquivos
- index.html: página principal (início, sobre, serviços, prévia da galeria, contato)
- galeria.html: galeria completa de fotos
- assets/css/style.css: estilos
- assets/js/script.js: menu mobile, botão de voltar ao topo, animações ao rolar a página
- assets/img: logo e fotos
