# Espaço Edi — Site institucional

Site presente para o Espaço Edi (Unhas e Depilação), São Bernardo do Campo, SP.
Instagram: @edi.unha.e.depilacao

## Stack
Site estático: HTML + CSS + JS puro (sem framework, sem back-end).

## Estrutura
- `index.html` — página principal (Início, Sobre, Serviços, prévia da Galeria, Contato)
- `galeria.html` — galeria completa de fotos
- `assets/css/style.css` — estilos
- `assets/js/script.js` — interatividade (menu mobile, ano no footer, etc.)
- `assets/img/` — logo e fotos
- `assets/data/` — dados auxiliares (se necessário)
